spxBoxWorld Game Engine, "Better Build survival game"

it's like a Minecraft world based on a toy I used to play with as a child, Betta Bilda small bricks you could build almost anything with.
It will be called Better build survival game,


Game start on a small island surrounded by water, with some basic resources you can dig in to the hill for bricks & tile blocks, trees for timber
so you can build your shelter, you need to find food & water  
When you reach a point a new island will be spawned you will need to build a bridge to get to it or use your boat  

start you will need to find your tools a spade, trawl, saw, hammer
We will need to restrict the players movement to only on the island blocks

Keys W,A,S,D Movement, 
Keys Esc exit, key 1 block mode, key 2 brick mode, key 3 window-door mode
key M mining, key H harvesting,
key arrow scroll tools,
